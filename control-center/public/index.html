      Words used here

      Journey
      One customer task from start to finish, such as buying a SIM. Each journey is also a business flow.
      Customer patience
      How long a customer waits before giving up. Slower than this and the order is abandoned.
      Abandoned or failed
      The value of orders customers gave up on, plus orders that failed.
      Business outcome
      A place where the business says no on its own, such as a declined payment, with nothing technically broken.
      Copies
      Identical running copies of one service. If one is stopped, requests go to the rest.
      Break / Start
      Stop or start one copy of a service.
      Latency
      A delay added to every request a service handles.
      Errors
      The share of requests that fail with a server error and a stack trace in the logs.
      Timeouts
      The share of requests that never get a reply.
      CPU burn / Memory leak
      A service uses more and more processor time or memory.
      Slow database query
      Database calls take much longer than they should.
      Dependencies fail
      Everything this service tries to call fails straight away.
      Metric cardinality explosion
      Every request creates a brand-new metric label, so the number of separate metric series grows without limit.
      Blind mode
      Hides which settings are changed, so the only way to find a problem is with your own tools.
      Trace id
      One identifier that follows a journey through every service, queue message and log line.
